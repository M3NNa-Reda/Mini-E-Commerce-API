# Mini E-Commerce API

A RESTful E-Commerce Web API built with ASP.NET Core to practice backend development concepts and build scalable APIs.

## 🛠️ Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
- Git & GitHub
